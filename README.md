# n8n-nodes-apivault-shopify-finder

Official n8n community node for the **Apivault Labs Website Leads Database**.

Search a large database of ecommerce and business websites, select platforms and countries, filter available fields, and return CRM-ready website records with public contact and firmographic data.

The package name remains `n8n-nodes-apivault-shopify-finder` so existing n8n installations can upgrade without replacing the community node.

## Installation

In n8n, open **Settings → Community Nodes → Install** and enter `n8n-nodes-apivault-shopify-finder`.

## Credentials

Create an **Apify API** credential in n8n and paste the token from **Apify Console → Settings → API & Integrations**.

## Features

- Search all platforms or select Shopify, WooCommerce, WordPress, Wix, Magento, BigCommerce, Squarespace and others.
- Filter by country, keyword, phone code, email availability and phone availability.
- Add conditions against any available database column.
- Select output columns or return fully enriched records.
- Sort by score, traffic rank, revenue, employees, technology spend, SKU, performance, SEO or freshness.
- Paginate with `offset`, deduplicate domains, or request counts only.
- Wait for results with resilient polling, or return the Apify run immediately for large exports.
